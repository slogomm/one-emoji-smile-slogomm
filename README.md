A minimal Node.js program that writes exactly one emoji — 🤗 — to satisfy the make.fun "One Emoji, One Smile" bounty.

## Run it

```bash
node --experimental-strip-types main.ts
```

The emoji will be written to `entry.txt` in the directory specified by `MAKEFUN_OUTPUT_DIR` (defaults to `/output`).
